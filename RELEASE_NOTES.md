# v1.0.0 — APC Mini MK1 Performance Script

**Highlights:** scoped scene launches; exclusive multi-clip launch; one-shot fills; one-slot pattern memory; automatic four-bar A/B rotation and fill-aware rotation transitions.

**Install:** extract the `APC_Mini_Rotation_Memory_v14_MK1` folder from the release ZIP into `Ableton/User Library/Remote Scripts`, restart Live 12, select the script in Settings → Link, Tempo & MIDI, and set the APC Mini MIDI ports as Input and Output.

**Compatibility:** original APC Mini **MK1** only, Ableton Live 12. Not tested on MK2. See README for all controls, limitations and troubleshooting.

**Note:** This release packages the V14 script *without altering the working controller code*. It is a community project and is not affiliated with Akai or Ableton.
