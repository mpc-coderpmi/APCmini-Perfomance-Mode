# Changelog

## [1.0.0] — 2026-11-11

First public MK1 release, packaged from the V14 performance script.

- Scoped scene launches within the current 8-track Session rectangle.
- Shift + pad(s): persistent exclusive multi-clip launch; cancels A/B rotation.
- Shift + 7 + pad(s): temporary fill and return; interrupts rotation and resumes at the next A/B block.
- Shift + 6 short/long press: single-slot pattern recall/save.
- Shift + 6 + pad(s): automatic four-bar A/B rotation.
- Shift + 6 + 8: cancel rotation without stopping playing clips.
- Stock APC Mini functionality and LED behavior retained through Ableton's built-in Remote Script.

## Historical development

The MK1 script was iterated through experimental versions V1–V14. Intermediate builds are not included in this release because several prototypes were unstable or not musically useful.
