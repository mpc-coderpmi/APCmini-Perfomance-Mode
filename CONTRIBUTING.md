# Contributing

Thanks for helping improve APC Mini MK1 Performance.

Before submitting changes:

1. Test the code on Ableton Live 12 with an actual APC Mini MK1 whenever possible.
2. Preserve the stock controller's basic pad launching, navigation, and LED feedback.
3. Describe how the change interacts with Shift + pad(s), Shift + 6 and Shift + 7.
4. Include reproducible steps and the Live version for any bug fix.
5. Confirm Python syntax with `python -m py_compile APC_Mini_Rotation_Memory_v14_MK1/__init__.py` (this is only a syntax check, not a Live integration test).

Please do not upload Ableton proprietary source files, copyrighted sample packs, live project material, or personal information in logs.
